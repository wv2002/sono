# Sono

App pessoal de registro de sono. Funciona offline e envia os registros para uma planilha do Google quando há internet.

- `index.html`: o app inteiro
- `planilha/Codigo.gs`: código que vai dentro da planilha (Apps Script). Este arquivo não é usado pelo site.
- `sw.js`, `manifest.json`, `icons/`, `fonts/`, `xlsx.mini.min.js`: arquivos para instalar e abrir sem internet
